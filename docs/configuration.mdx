# Configuration

To see and change the options, run `/config` in a session, or this command in a shell:

```bash
claude plugin configure code-mode@claude-code-mode
```

The options are in `pluginConfigs["code-mode"].options` in your Claude Code settings. All options are optional.

| Option | Default | What it does |
| --- | --- | --- |
| `node` | `node` | The Node.js executable for the sandbox: a name on `PATH` or an absolute path. It must be Node 22.13 or later. |
| `timeoutSeconds` | `120` | The wall-clock limit and the CPU limit for one program, in seconds. The minimum is 5. |
| `blockDirectMcp` | `false` | If `true`, the plugin denies the MCP calls that the model makes directly, so the model must use `run_code`. Nested calls are not blocked. |
| `approval` | `program` | `program`: your approval of `run_code` covers the nested calls that no rule decides. `per-call`: each nested call has its own check. See [Permissions](./permissions.mdx). |
| `projectHints` | `false` | If `true`, the plugin also loads hints from `.claude/code-mode/hints/` in the project. Turn it on only for projects that you trust. See [Hints](./hints.mdx#safety-rules). |
| `projection` | `true` | The result of a run shows the size and the shape of each MCP result. A later program can read a result again with `recall(n)`. If `false`, the result shows only the number of MCP calls. See [Output projection](./usage.mdx#output-projection). |
| `metrics` | `false` | If `true`, the plugin writes one line with sizes and counts for each run to `~/.claude/code-mode/metrics/`. See [Output projection](./usage.mdx#output-projection). |

A change to an option reloads the plugin.
